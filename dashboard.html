Sobre o projeto

Um launcher independente, feito a partir das tuas ideias.

O Game on Launcher junta gestão de jogo, conta e conteúdo numa aplicação macOS. O motor de jogo é interno e o Prism Launcher só é descarregado quando precisas de loaders com mods.
